# 个人 Agent App

这个 fork 的手机首页连接自己的 `raft-ccdriver`。主 Agent、worker、文件和记忆保存在服务端，手机和网页访问同一个个人工作空间。

## 连接

先让手机通过 NetBird 客户端加入私网，再使用证书有效的 HTTPS 服务地址。App 的连接地址由你填写。

在 Raft 网页的主对话中展开「个人助理工作台 → 连接手机」，生成一次性配对码。在手机「连接」页填写服务器地址、配对码和设备名称。配对码五分钟有效，只能兑换一次；设备授权七天有效，到期后重新配对。更换或解除主 Agent 绑定后也需要重新配对。不要填写管理员令牌或模型密钥。

在「对话」中与现有主 Agent 沟通，在「工作」中查看 worker 状态、结果和停止任务。主会话线程中的回复也会出现在手机对话中。发送失败时使用「用原请求重试」；尚未确认的消息会保留，重启 App 后仍使用同一个请求键。回到前台或网络变化时自动同步，离线期间的服务器任务继续执行。

「解除设备授权」会撤销本设备的服务端授权；也可以在 Raft 网页的设备列表中撤销。「仅移除本机连接」只删除本机凭据，之后仍需由所有者撤销服务端授权。对话缓存保存在 App 本机存储中，显示最近五百条消息。原生账号退出全部会话后，手机授权也会失效。

当前 Raft 接入的运行时问题和审批请在网页处理；App「待处理」页会根据服务端能力提示未开放。若以前提交的操作尚未取得回执，会继续保留，待在网页核对后再结束跟进。该接入已通过现有客户端逻辑的配对、真实对话和撤销授权验证；原生设备安装验收、推送通知、连续流式输出和授权自动续期尚未完成。

## 开发

按照根目录说明安装 Vite+，使用仓库要求的 Node 版本并运行 `vp i`。在有可用模拟器或设备的机器上运行 `vp run mobile:install ios` 或 `vp run mobile:install android`，随后在 `apps/mobile` 运行 `vp run dev:client`。

开发版标识是 `com.ccdriver.personal.dev`，链接 scheme 是 `ccdriver-dev`。仅开发版允许回环地址的 HTTP。生产版要求 HTTPS。地址由运行时填写，凭据进入系统安全存储，不写入构建变量。

此 fork 使用独立的应用标识，关闭上游的更新通道、云端登录和默认共享原生构建缓存。正式签名和商店分发需要配置自己的开发者账户。
